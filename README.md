# 矩阵内容助手

餐饮营销用的 Chrome / Edge 插件 + 配套工具。

## 功能
- **调研**：小红书/抖音竞对、同城热门店、全国对标调研；顾客需求点、深度洞察（菜品榜、吸引因素、场景客群、阻碍）、爆款拆解
- **门店评价调研**：导入大众点评评价（商家后台导出或手机采集），按《顾客评价调研模块》模板 AI 归纳
- **爆款库**：按内容类型 × 场景 × 品类收集小红书/抖音餐饮爆款，自动打分和拆解，被推荐榜
- **评论**：维护自家帖子的评论区（分类、回复草稿、填入回复框、高频问题）
- **内容 / 模板 / 账号 / 数据**：多账号人设内容生成、模板库、账号库、发布数据回读

## 目录
| 目录 | 说明 |
|---|---|
| `extension/` | 插件本体，Chrome 里"加载已解压的扩展程序"选这个文件夹 |
| `shared/` | 插件和网页版共用的代码（改这里，再运行 `python build.py` 同步到 extension/） |
| `web/` | 网页版 |
| `report/` | 评价调研报告页 + 评价归纳逻辑（pipeline.js） |
| `dianping-collector/` | 大众点评 App 评价采集工具（Windows + 安卓手机数据线），用法见里面的使用说明 |
| `build.py` | 构建脚本：同步 shared/ 到 extension/，生成网页版和插件压缩包 |

## 安装插件
1. 打开 `chrome://extensions`，打开"开发者模式"
2. 点"加载已解压的扩展程序"，选 `extension` 文件夹
3. 详细用法见 `extension/使用说明.txt`

## 说明
- AI 功能使用你自己填写的 API 密钥（DeepSeek / 通义千问 / Kimi / 豆包 / Claude），密钥只保存在本机浏览器，不在代码里
- 采集到的评价、调研数据只保存在本机，不在仓库里

矩阵内容助手 · Chrome / Edge 插件

【安装 / 更新】
1. 解压 zip，得到"矩阵内容助手"文件夹（放在固定位置，不要删）
2. 地址栏打开 chrome://extensions（Edge 是 edge://extensions），打开"开发者模式"
3. 首次：点"加载已解压的扩展程序"选这个文件夹；更新：覆盖文件后点插件卡片上的刷新按钮
4. 刷新已经打开的小红书/抖音页面

【第一次用：先设置】
设置 → 默认行业：选你的行业（餐饮、茶饮咖啡、美业、健身、教育、酒店民宿……或通用）
设置 → AI（可选）：填 API 密钥后可用"AI 按人设写""用 AI 归纳需求"。推荐 DeepSeek（platform.deepseek.com，充值几块钱够用很久）
账号 → 添加矩阵号，或"批量导入"表格（先点"下载导入模板"）。每个号填：分组、人设、语气、每周目标、门店信息

【调研：找竞对 / 同城热门店 / 全国对标】
1. 选「平台内容调研」，选行业、平台（小红书 / 抖音，可都选，会一次跑完合成一份报告），再选调研方式：
   · 品牌/竞对对比：一行一个品牌，2 个以上会并排对比
   · 同城热门店：城市（+商圈）+ 品类，找出被反复推荐的店
   · 全国对标：品类（+定位），找全国被讨论最多的品牌
   · 自定义关键词：自己写关键词和"必须包含"的词
2. 看一眼"将搜索的关键词"，可以改、删、加
3. 选每个关键词抓几篇、每篇几条评论、发布时间（默认近一年）、抓取顺序（默认互动最多的先抓）
4. 开始调研：会打开新窗口自动浏览。先登录选中的平台；遇到验证会自动暂停，完成后点"继续"
5. 报告：
   · 深度洞察（要先在设置里填 AI 密钥）：AI 逐条读完帖子、评论和评价，告诉你
     顾客喜欢点什么菜/产品（好评率、被夸和被吐槽的具体点）、什么吸引他们来、谁在来/什么场景、
     什么让他们不来；多个品牌时有品牌画像对照。选"我们的品牌"后，机会点和 10 个选题会站在你的角度给出
   · 需求点：顾客的不满 / 想要 / 疑问 / 吸引，按人数排序；AI 归纳后每个需求点下面有各品牌占比；点"写成内容"直接去生成
   · 竞对对比 或 店铺榜/品牌榜
   · 爆款拆解：哪种标题更容易火、标题长度、高频话题、发布时段、图文还是视频；爆款可以"仿写"或"转模板"
   · 导出 Excel

【门店评价调研（大众点评）】
调研 → 门店评价调研。两种来源：
A. 用手机采集（推荐）：大众点评网页版不开放全部评价，用「点评采集工具」连手机从 App 里采，得到的表格用下面 B 的方式导入
   导入后能看到推荐菜、人均、星级分布等
B2. 网页版抓取（只能拿到店铺页的部分评价和评价标签）：
   1. 一行一家门店。粘贴大众点评店铺链接最准；也可以写"品牌 分店"（如：小炳胜 天河店）+ 城市
   2. 选评价时间（默认近一年）、每家最多抓多少条（默认 1000）
   3. 点"下一步：确认门店"，勾选是哪一家（可以勾多家分店），再点"开始抓取"
   4. 插件会切到"最新"排序，一页页往下翻，读到时间范围之外就停。1000 条约 8–15 分钟
   先登录大众点评；遇到验证会暂停，处理完点"继续"
B. 导入评价表格：自己门店建议用这个。把美团/点评商家后台导出的评价表（.xlsx/.csv）导入，确认"评价内容/日期/星级"是哪几列
报告：
   · 数据概览：评价数、平均星级、3 星及以下占比、星级分布、口味/环境/服务分、每月评价数和月均星级、顾客勾选的"喜欢的菜"
   · 评价归纳（AI）：按你们的《顾客评价调研模块》模板出六部分——好评产品、差评产品、具体口碑点、具体吐槽点（含影响级别）、内容拍摄结论、客流特征和最终结论；内容拍摄结论可以一键"写成内容"
   · 多家门店都归纳后，有门店对比
   · 表格比较宽，可以点"大屏查看"在新标签页打开
   · 导出 Excel：模板同格式的调研表 + 数据概览 + 每条评价的打标明细

【爆款：小红书/抖音餐饮爆款库】
1. 爆款 → 采集设置：勾选平台、城市/商圈、品类、场景、内容类型（询问/攻略/素人分享/探店/避雷/氛围/活动，类型词可改），填竞品和"我们的品牌"
2. 下面实时显示组合出来的关键词：不想要的点 ✕，也可以自己加；每次按优先级轮换一批（没搜过的、出爆款多的优先）
3. 点"立即更新"：搜索 → 去掉无关/互动太低的 → AI 分内容类型、场景、品类 → 同类型内打"值得学指数" → 排名靠前的读正文和评论 → AI 拆解
4. 爆款库：按类型/场景/品类筛选；每张卡片有"为什么火"、标题公式、结构、卖点、评论区在问什么、可复制程度、合规提醒、可复用模板
   "转模板"存进模板库，"仿写"直接给矩阵号生成；👍👎 标"值得学/不值得学"，用来校准
5. 被推荐榜：从询问帖评论和攻略合集里统计哪些店被推荐最多、为什么，看"我们的品牌"排第几
6. 系统建议的新词：从爆款的话题和关键词里提取，点"要"才加入
7. 对标账号：采集设置 ⑦ 粘贴博主主页链接（小红书 /user/profile/…，抖音 /user/…）。"只查对标账号"或"立即更新"时会看他们的新作品，
   按昨天以来 / 近 7 天 / 更早分组，互动是这个号平时 3 倍以上的标"本号爆文"
8. 二创工作台：任意卡片点"二创"→ 选写成图文笔记还是口播脚本（带镜头）、发在哪个账号、这次主推什么 → 生成
   每一句标出作用和对应原爆款的哪一句；每句都能直接改、单独"AI 重写这句"、上移/加一句/删除；可复制全文或存为模板
值得学指数：询问帖看评论、攻略看收藏、其他看互动（抖音有粉丝数时看粉丝倍数），再加涨速、收藏率、评论里的到店意图

【评论：维护自己帖子的评论区】
1. 评论 → 门店资料：填地址、营业时间、人均、招牌菜、排队/预约等（回复只会用这里的事实）
2. 帖子来源：「数据」发布记录里填了链接的帖子会自动出现；也可以在"帖子列表"里粘贴链接
3. 点"检查新评论"：插件逐个打开帖子读评论，自动分类（差评、问价格、问地址、问排队、问点什么、夸奖、闲聊），
   我们账号已经回过的会自动标成已处理；设置了 AI 会按店长口吻写回复草稿
4. 看草稿、改一改 → "填入回复框"：插件打开帖子、找到那条评论、点回复、填好文字，你检查后自己点"发送"，回来点"已回复"
5. "顾客最常问"汇总所有提问，可以一键生成置顶评论，或"写成内容"做下一篇
注意：只用店家身份回复自家帖子；回复由你本人确认发送

【内容：三种来源】
· 模板：按行业、场景、效果排序挑模板
· 调研需求：选报告里的一个需求点，写一句"我们的做法/答案"
· 爆款仿写：选报告里的一篇爆款
选账号（可整组选）→ 填本次信息 → "AI 按人设写"或"模板生成（差异化）"
每张出品单：复制 / 填入发布页 / 记为已发布

【数据】
发布后在"发布记录"里粘贴帖子链接 → "批量更新数据"自动读回赞藏评转
按账号 / 按模板 / 按人设 / 时段与趋势 看效果；模板页"效果最好"按这里的数据排序

【换电脑】
设置 → 导出全部（JSON），新电脑导入。AI 密钥和调研报告不在备份里（报告可导出 Excel）

【注意】
· 采集用你自己登录的账号，按正常浏览速度进行；同一账号一天别跑太多
· 店铺/品牌榜是从帖子文字里自动识别的，可能夹杂少量非店名，以原帖为准
· 大众点评部分文字用了加密字体，插件会尽量还原，个别字可能缺失
· 如果一条评论都读不到，报告顶部有"复制诊断信息"，发给 Claude 帮你修

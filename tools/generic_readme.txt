矩阵内容助手 · 使用说明（版本 {VER}）
========================================

这是一个 Chrome 浏览器插件，主要做三件事：
1. 评论采集：贴小红书笔记或抖音视频的链接，把下面的全部评论（连同楼中楼回复）拉出来，写进你自己的飞书多维表格，再用你自己的大模型（推荐 DeepSeek）做一份总结。
2. 平台内容调研：按关键词在小红书 / 抖音上看竞对、同城热门、爆款内容和顾客在问什么。
3. 内容生成：按模板和账号人设写小红书 / 抖音文案。

你的飞书凭证、大模型密钥都只保存在你这台电脑的浏览器里，插件不会把它们发给任何第三方服务器。
拉评论用的是你这个浏览器里登录的小红书 / 抖音账号。


一、安装插件（5 分钟）
----------------------
1. 把压缩包解压到一个固定的文件夹（比如 桌面\矩阵内容助手），以后别删、别挪。
2. 打开 Chrome，地址栏输入 chrome://extensions 回车。
3. 打开右上角的「开发者模式」。
4. 点左上角「加载已解压的扩展程序」，选刚才解压出来的那个文件夹（里面能直接看到 manifest.json 的那一层）。
5. 点浏览器右上角的拼图图标，把「矩阵内容助手」固定到工具栏。以后点这个图标，右边就会打开插件的侧边栏。
6. 在这个 Chrome 里登录小红书网页版（www.xiaohongshu.com）和抖音网页版（www.douyin.com）。

以后插件有新版本：把新文件覆盖到同一个文件夹，再到 chrome://extensions 里点插件卡片上的刷新按钮。


二、填大模型密钥（做评论总结、调研分析、写文案都要用）
------------------------------------------------------
1. 打开 https://platform.deepseek.com ，注册登录，充一点余额（总结一条帖子的评论通常几分钱），在「API Keys」里新建一个 Key，复制下来。
2. 插件侧边栏 →「设置」→「AI」那一块：「用哪家 AI」选 DeepSeek，把 Key 粘进「API 密钥」，点「保存」，再点「测试连接」，提示成功就好了。
   也可以用通义千问、Kimi、豆包等，选对应的服务商并填它的 Key。


三、连接你自己的飞书（评论采集要用）
------------------------------------
第 1 步：建一个飞书应用（需要飞书企业管理员权限，或者请管理员帮你审批）
  1. 用电脑浏览器打开 https://open.feishu.cn ，右上角进入「开发者后台」。
  2. 点「创建企业自建应用」，名字随便起，比如「评论采集助手」。
  3. 左边「凭证与基础信息」里，复制 App ID 和 App Secret，等会儿要填进插件。
     App Secret 相当于密码，不要发到群里，也不要发给别人。
  4. 左边「权限管理」，搜索并开通：
     - 查看、评论、编辑和管理多维表格（bitable:app）
     - 如果你的表格放在知识库（链接里是 /wiki/），再开通：查看知识库（wiki:wiki:readonly）
  5. 左边「版本管理与发布」→ 创建版本 → 申请发布。管理员在飞书里审批通过后，应用才能用。

第 2 步：建一个多维表格，并把应用加进去
  1. 在飞书里新建一个多维表格（名字随便，比如「评论采集」）。
  2. 打开这个表格，点右上角「…」→「更多」→「添加文档应用」，搜你刚建的应用，权限选「可编辑」。
  3. 复制浏览器地址栏里这个表格的完整链接（里面有 /base/ 或 /wiki/）。

第 3 步：填进插件
  1. 插件侧边栏 →「飞书」→「飞书连接」右边点「设置」。
  2. 填 App ID、App Secret、多维表格链接，点「保存并测试连接」。
  3. 提示成功后，你的表格里会自动多出两张表：「评论采集」和「评论总结」。


四、拉评论
----------
1. 插件侧边栏 →「飞书」，把小红书笔记或抖音视频的链接贴进「链接」框。
   一行一个；直接粘 App 里「分享 → 复制链接」的整段文字也可以，插件会自己认出链接。
2. 点「拉全部评论」。插件会弹出一个小窗口，像人一样慢慢往下翻评论、点开「展开 N 条回复」。
3. 拉完自动写进飞书「评论采集」表：一条评论一行，有评论内容、评论人、类型（评论 / 回复）、回复给谁、是不是作者回复、点赞、评论时间、IP 属地、帖子标题和链接。
4. 接着用你的大模型做总结（大家的态度、夸什么、吐槽什么、问什么、提到的竞品、可做的选题、该优先回复哪几条），写进「评论总结」表，插件里也能直接展开看。
5. 同一个链接以后再拉一次，只补新评论、更新点赞数，不会重复。

注意：
- 拉的时候，弹出的那个窗口不要关，也不要最小化（最小化后平台不加载评论）。
- 平台弹出验证（滑块、点选文字），窗口会自动跳到最前面，你把验证点完就行，插件会自己接着拉。
- 评论几千条的帖子要十几分钟到半小时。一次贴三五条链接比较稳，短时间拉太多容易被平台频繁要求验证。
- 总结时评论太多，会按点赞从高到低取前面一部分交给大模型；全部评论都在「评论采集」表里。


五、其他功能
------------
- 调研：填品牌或关键词，插件在小红书 / 抖音上读搜索结果和评论，整理竞对、爆款和顾客需求，能导出 Excel。
- 爆款：收藏和拆解高赞内容。
- 模板：按行业模板和账号人设写文案（要先在「设置」里填大模型密钥）。


六、常见问题
------------
- 「飞书凭证不对」：检查 App ID / Secret 有没有复制全；应用要发布成功后才能用。
- 「应用没有这个多维表格的权限」：回到第三部分第 2 步，把应用加成表格的「可编辑」文档应用。
- 「应用缺少权限」：到飞书开发者后台给应用开通多维表格权限，再创建一个新版本发布。
- 读到的评论比帖子上显示的少：帖子显示的数字包含已删除、被折叠的评论；另外检查拉的时候窗口是不是被最小化了。
- 总结没做成：到「设置」里看大模型密钥和余额。
